Projektanforderung: Interaktive Bücherliste

Es soll eine Bücherliste mit noch zu lesenden Büchern erstellt werden. Folgende Kernfunktionen sind umzusetzen:

  • Ein Input-Feld, welches ein Array befüllen kann.
  • Das Array soll auf der Seite gerendert (angezeigt) werden.
  • Man soll einzelne Einträge des Arrays löschen können.

Hinweis: Gerne etwas designen, wenn das Projekt früher fertig ist oder als Zusatzaufgabe.

Zusatzaufgaben:

  • Zweites Array ("Gelesene Bücher"): Man kann gelesene Bücher (z. B. indem man auf den Namen des Buches klickt) zu einem zweiten „Gelesen“-Array hinzufügen. Diese Liste soll ebenfalls angezeigt werden.
  • Local Storage: Das Ganze wird im Local Storage des Browsers gespeichert, damit die Daten beim Neuladen erhalten bleiben.
